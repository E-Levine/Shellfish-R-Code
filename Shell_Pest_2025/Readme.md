# Shell Pest 2025

PROJECT DESCRIPTION:  <br>
Code to determine if AB Shell Pest data shows evidence of useful relationships we should continue to focus on. <br><br>

PROJECT STATUS:  <br>
This project is currently completed. <br><br>

DETAILS:  <br>
A large amount of Shell Pest data now exists from AB and ImagePro processing. Model fitting tests were performed here to check that: <br>
1) Evaluate relationships between Shell Pest data and external factors <br>
2) Appropriate statistical tests are applied to each pair of variables <br><br>

Data collected and summarized by these methods include: <br>
1) Prevalence - rate of occurrence between 0 - 100% <br>
2) Intensity - percent of surface coverage 0 - 100% (sponge and worm), number of clams;  <br><br>

Of three boring pests:<br>
i) Sponge (Cliona) <br>
ii) Worm (Polydora) <br>
iii) Clam (Diplothyra) <br>

Visible in: <br>
a) Whole oyster <br>
<br>

Variables being investigated for a relationship with the above data includes: <br>
A) Section (West, Central, East) <br>
B) Trend over time (2016 - 2022) <br>
C) Annual trend (by Month, by Season) <br>
D) Oyster size (Shell Height, Total Weight) <br>
E) FixedLocationID (within section variability<br>
F) ObserverID (impact of observer bias on data) <br> <br>

OUTPUTS: <br>
HTML file generated from RMarkdown files for clam, cliona, and polydora <br> <br>

CONCLUSIONS: <br>
A) Discontinue all shell pest data collection and data processing <br>
B) Require reprocessing data with QA requirements for future use of data. <br>
