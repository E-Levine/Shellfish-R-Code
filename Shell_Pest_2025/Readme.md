# Shell Pest 2025

PROJECT DESCRIPTION:  <br>
Code to determine if AB Shell Pest data shows evidence of useful relationships we should continue to focus on. <br><br>

PROJECT STATUS:  <br>
This project is currently under development. Code is still being refined. <br><br>

DETAILS:  <br>
A large amount of Shell Pest data now exists from AB and ImagePro processing. Simple tests are performed here to check that: <br>
1) Assumptions of normality and variance hold or fail <br>
2) Appropriate statistical tests are applied to each pair of variables <br><br>

Data collected and summarized by these methods include: <br>
1) Prevalence - rate of occurrence between 0 - 100% <br>
2) Intensity - percent of surface coverage 0 - 100% <br><br>

Of three boring pests:<br>
i) Sponge (Cliona) <br>
ii) Worm (Polydora) <br>
iii) Clam (Diplothyra) <br>

Visible in: <br>
a) Whole oyster <br>
b) External surfaces <br>
c) Internal surfaces <br>
d) Top shell <br>
e) bottom shell <br> <br>

Variables being investigated for a relationship with the above data includes: <br>
A) Section (West, Central, East) <br>
B) Trend over time (2016 - 2022) <br>
C) Annual trend (by Month, by Season) <br>
D) Oyster size (Shell Height, Total Weight) <br><br>

OUTPUTS: <br>
Table 1 - Show the relationship types between variable (Numeric vs. Numeric, Numeric vs. Categorical, etc.) <br>
Table 2 - Results of normality and variance assumptions <br>
Table 3 - Test used to evaluate relationship <br>
Table 4 - p-values for tests <br>
